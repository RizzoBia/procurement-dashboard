# Procurement Dashboard

Sistema de Gestão de Suprimentos moderno e responsivo, desenvolvido com **React** e **Vite**.

## Funcionalidades
- Dashboard Executivo
- Visão Operacional Detalhada
- Acompanhamento de Performance e Savings
- Gestão de SLAs
- Suporte a Modo Claro e Escuro (Dark Mode)

## Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/beatriztrizzo/procurement-dashboard.git
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

## Tecnologias Utilizadas
- React 18
- Vite
- Recharts (Gráficos)
- Lucide React (Ícones)
- CSS Puro (Glassmorphism e Variáveis de Tema)
